## ⚡ 1. Testing Philosophy & Budget

1. **Sub-1s Unified Suite Target:** All pure domain entities, financial calculations, application use cases, and React frontend component interactions execute in under 1 second (observed ~940ms) using Vitest, enabling instantaneous TDD feedback loops.
2. **In-Memory DOM Simulation (`happy-dom`):** Level 2 frontend UI component tests leverage `happy-dom` and `@testing-library/react` rather than heavy headless browser binaries (e.g. Playwright or Puppeteer). This eliminates cold-start latency and browser engine crashes while thoroughly testing real user interaction flows.
3. **Zero External Network Dependence in CI:** Unit and use case tests never make live HTTP calls to the Frankfurter API during test runs. Instead, they leverage isolated in-memory repositories and mock exchange rate gateways with deterministic test fixtures.
4. **Deterministic State Isolation:** Every test suite instantiates fresh in-memory repository instances (`InMemoryWalletRepository`, `InMemoryTransactionRepository`), eliminating state leakage between test cases.
