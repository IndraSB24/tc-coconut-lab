## 🏛️ 2. Key Architectural Invariants

1. **Domain-Driven Isolation (Clean Architecture):**
   Business logic and transaction invariants reside strictly inside `src/core/use-cases/`. Next.js HTTP adapters (`src/app/api/`) and Prisma repository adapters never leak into domain entities.
2. **Unified API Envelope:**
   Every REST endpoint returns a standard JSON payload: `{ success, data, error, meta }`.
3. **Simulated User Session:**
   Utilizes a lightweight mock session with zero external auth library bloat (NextAuth, OAuth, JWT), ensuring instant test evaluation.
4. **Resilient Gateway with Circuit Fallback:**
   The external exchange rate service features in-memory caching and offline fallback, ensuring high test resilience even in disconnected sandbox environments.
