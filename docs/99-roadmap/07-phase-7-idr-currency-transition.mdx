This phase executes the architectural ratification to transition from **Japanese Yen (`JPY`)** to **Indonesian Rupiah (`IDR`)** as the designated zero-decimal foreign exchange wallet. IDR shares the identical financial invariant profile as JPY (0 decimal places per ISO 4217, whole units), while significantly enhancing presentation relatability and validating system resilience with large-scale financial integers (millions/billions with localized thousands separators).
