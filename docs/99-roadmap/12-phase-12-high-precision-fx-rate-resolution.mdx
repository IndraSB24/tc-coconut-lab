This phase addresses an insidious **floating-point underflow bug** that occurs when converting high-denomination currencies (e.g., `IDR` or `JPY`) into high-value currencies (`EUR`, `GBP`, `USD`). Inverting exchange rates where 1 USD ≈ 16,000 IDR produces micro-rates (≈ 0.0000475 - 0.000058 units per IDR). Under legacy 4-decimal truncation (`* 10000 / 10000`), these values round to exact zero (`0.0000`), causing conversion yields to evaluate to `0.00 EUR` and freezing transactions. 

Phase 12 refactors the rate engine across backend resilience fallback, frontend live calculation, and adaptive UI ticker display to guarantee **8-decimal sub-unit precision (`10^-8`)**.

## 📋 2. Detailed Technical Specifications

### 2.1 Track A: Backend Fallback Precision
1. **Triangular Arbitrage Precision Upgrade:**
   - In [`FrankfurterExchangeRateService.ts`](file:///Users/user/Documents/Personal/tc-coconut-lab/app-core/src/infrastructure/services/FrankfurterExchangeRateService.ts):
     ```typescript
     public calculateFallbackRate(base: string, quote: string): number {
       const usdToBase = STATIC_USD_RATES[base] ?? 1.0;
       const usdToQuote = STATIC_USD_RATES[quote] ?? 1.0;

       // 8-decimal high-precision triangular arbitrage guard
       const rate = usdToQuote / usdToBase;
       return Math.round((rate + Number.EPSILON) * 100000000) / 100000000;
     }
     ```
   - Resolves `IDR -> EUR` fallback rate from `0` to `0.00005804`.
   - Resolves `IDR -> GBP` fallback rate from `0` to `0.00004984`.

### 2.2 Track B: Frontend Live Rate Preview & Adaptive Ticker
1. **Page-Level Arbitrage Preview (`page.tsx`):**
   - In [`src/app/page.tsx`](file:///Users/user/Documents/Personal/tc-coconut-lab/app-core/src/app/page.tsx):
     ```typescript
     const getSelectedConversionRate = () => {
       const fromW = wallets.find((w) => w.id === fromWalletId);
       const toW = wallets.find((w) => w.id === toWalletId);
       if (!fromW || !toW || fromW.currency === toW.currency) return 1.0;

       const directKey = `${fromW.currency}_${toW.currency}`;
       if (rates[directKey]) return rates[directKey];

       const usdToFrom = rates[`USD_${fromW.currency}`] || (fromW.currency === 'USD' ? 1.0 : 1.0);
       const usdToTo = rates[`USD_${toW.currency}`] || (toW.currency === 'USD' ? 1.0 : 1.0);
       return Math.round((usdToTo / usdToFrom + Number.EPSILON) * 100000000) / 100000000;
     };
     ```
2. **Adaptive Ticker Display Formatting (`WalletActionWorkbench.tsx`):**
   - When displaying `1 IDR = X EUR`, if `rate < 0.01`, format using `rate.toFixed(6)` or locale string with up to 8 decimal places:
     ```typescript
     const formattedRate = rate < 0.01 ? rate.toFixed(6) : rate.toFixed(4);
     ```
   - Avoids confusing `1 IDR = 0 EUR` badge; renders clear `1 IDR = 0.000058 EUR`.
