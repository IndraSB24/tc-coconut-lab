This phase eliminates raw HTML `<input type="number">` limitations across the workbench by extracting a dedicated, enterprise-grade reusable **Masked Currency Input** component (`CurrencyAmountInput.tsx`). It provides real-time thousand separators (`15,000,000`), eliminates premature auto-decimals, enforces zero-decimal invariants on `IDR`, and maintains clean unmasked numerical state propagation to domain forms.
