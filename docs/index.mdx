Welcome to the technical architecture documentation portal for the **Multi-Currency Digital Wallet Application** built for the **Coconut Lab** live coding challenge.

This system follows **Domain-Driven Design (DDD)**, **Clean Architecture**, and **Living SSOT (Docs-as-Code)** standards. All domain invariants, double-entry financial accounting rules, and API specifications are documented here as machine-verifiable truth.

## 🚀 Quick Execution Guide

Run both the runtime application and this interactive documentation portal concurrently:

```bash
# 1. Run the Runtime Application (Next.js 16 on Port 3000)
npm run dev

# 2. Run the Interactive Documentation Portal (Docusaurus on Port 7001)
npm run docs:dev

# 3. Run Automated Unit Tests (Vitest)
npm test
```
