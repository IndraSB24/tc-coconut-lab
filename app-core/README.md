# 🥥 Coconut Lab — Multi-Currency Digital Wallet (App Core)

This directory contains the **runtime application engine** for the Coconut Lab live coding challenge, built with Next.js App Router, TypeScript, Prisma ORM, and SQLite.

For setup, architecture blueprints, API documentation, and test verification, please refer to the primary root documentation:
- Root Guide: [../README.md](../README.md)
- Living Architecture SSOT: [../docs/](../docs/)
- Context Map: [../CONTEXT-MAP.md](../CONTEXT-MAP.md)

### Quick Commands (from workspace root)
```bash
# Start Next.js development server (Port 3000)
npm run dev

# Run automated test suite (47 unit tests in < 1s)
npm test

# Launch Docusaurus Architecture Portal (Port 7001)
npm run docs:dev
```
